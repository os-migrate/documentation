= Migrating virtual machines from VMware to OpenStack

[role="_abstract"]
Use the VMware Migration Kit (os_migrate.vmware_migration_kit) Ansible collection to migrate virtual machines from VMware vSphere environments to OpenStack. The migration process includes discovery, pre-migration preparation, and migration execution phases. You can perform migrations from the command line or through AWX (or Ansible Automation Platform) for automation and orchestration.
