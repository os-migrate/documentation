= Creating credentials for AWX

[role="_abstract"]
Create credentials in AWX (or Ansible Automation Platform) to authenticate with the conversion host during migration.

.Procedure

. From the navigation panel, select the AWX or automation controller UI, then `Infrastructure`, then `Credentials`.
. Click `Create Credential`.
. Set the following parameters:
+
----
Name: Conversion Host SSH Key
Credential Type: Machine
Username: cloud-user
SSH Private Key: <paste your SSH private key>
----
+
where:
+
`SSH Private Key`:: Paste the SSH private key that corresponds to the public key configured on the conversion host. This is typically the key you specified when creating the conversion host instance.

. Click `Create Credential`.

The credential is available for use in job templates.
