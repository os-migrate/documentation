= Migrating workloads between OpenStack clouds

OS Migrate copies tenant content between OpenStack clouds using the official OpenStack API. This guide describes how to
prepare the clouds, deploy the conversion hosts, migrate the supporting resources, and migrate the workloads. For the
components shared with other migration types, see the common reference at the end of this guide.
